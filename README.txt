# Cascaded DDPG Drone Control (Simulink)

## Overview
This project demonstrates a cascaded DDPG control framework in MATLAB/Simulink for quadcopter trajectory tracking.

## Features
- Cascaded control architecture
- Reinforcement learning (DDPG)
- Simulation-based trajectory tracking
- Proof of trained result are included.

## How to Run
1. Open the Simulink model
2. Run the MATLAB script
3. Use your own trained agents

## Note
Trained agent files are not included.
